# SYSTEMWIRE・内网安全智能体平台（AI Security Agent Demo）

对话驱动的内网安全智能体演示：Agent 为主体（Codex / Claude Code 式对话形态），
三栏 SOC 大屏风格控制台，基于 **CopilotKit 1.73（React 19 / Next.js 15 App Router）** 构建。

**纯前端演示，不接真实安全工具**：安全工具由 CopilotKit Runtime 真实执行、返回模拟数据
并渲染 HUD 可视化卡片；大模型默认走内置「演示脚本」引擎（拦截 OpenAI 兼容
`/chat/completions`，SSE 流式 + 打字机 + 工具调用编排），**离线 100% 可复现**；
可一键切换真实 **DeepSeek**，请求失败（断网 / Key 失效 / 超时）自动回退演示脚本。

### 蜜点部署规则（演示口径）

- **每节点最多 3 枚诱饵**（异类型共存，同类型重复部署返回「已在运行」）。
- **可行性判断**：PLC（109）/ 打印机（110）/ 摄像头（111）/ 交换机（112）为封闭实时设备，
  不支持部署（红色 BLOCKED 卡）；网关（.1）仅支持 WEB；服务器按暴露面推荐模板
  （105→SSH、107→SQL、103→SMB、网关→WEB）。
- **端口冲突四方案**（以 107 MySQL 占用 3306 为例）：
  A 备用端口（推荐，3306→13306，影响低）/ B 停真实服务（影响高）/
  C 反向代理（影响中）/ D 改投其他节点（105·108，影响低）。
  无冲突时为单方案授权卡；SSH 22→2222、WEB 80→8080、SMB 445→1445 同理。
- **两种授权模式**（左下角 AUTHORITY）：默认「逐次确认」，每次部署/卸载弹 HITL 卡；
  「自动执行」演示 Agent 自主决策链路（105·SSH → 网关·WEB 链式部署）。
  授权卡上可勾选「本次会话对同类部署自动批准」（按诱饵类型记忆，冲突时自动采用推荐端口）。
- **卸载为有后果操作**：同样走授权确认（停止诱饵 / 释放端口 / 日志归档 30 天），
  108 的 SSH 诱饵卸载前会提示其承载历史告警。
- 108 预置一枚 SSH 诱饵（:2222），即归因页告警的来源。

### 攻击链剧本与多告警数据

- 主战役 **C-0919**：103 上复用离职账号 wangwei 暴力破解 105（T1110）→
  利用 MS17-010 横向到 108（T1210）→ 触发 SSH 诱饵并回连探测网关（T1078），
  研判置信度 **87%**（26+24+22+15 四因子，4 层杀伤链）。
- 9 条告警覆盖 critical/high/medium/low 与待研判/研判中/已闭环/误报四种状态，
  分属 C-0919 / C-0917 / C-0912 三个攻击活动；支持「下一条待研判」轮询、
  显式告警 ID（如 `ALERT-2026-0917-001`，3 层 / 62%）、攻击活动 C-编号、
  实体关联（IP / 账号 / IOC / TTP，如「分析关联事件 wangwei」）。
- **误报样本 ALERT-2026-0906-001**：运维巡检计划任务触发，2 层 / 置信度 25%，
  绿色良性研判（来源、时间、行为与白名单吻合）。

## 启动方式

```bash

# —— 推荐演示方式：生产构建（首屏快、无开发态浮标、行为最稳定）——
pnpm build
pnpm start          # http://localhost:3000

# —— 开发模式（热更新；首次编译较慢，属正常现象）——
pnpm dev
```

> 没有 pnpm 时可用 node 直接调 Next：
> `node node_modules/next/dist/bin/next build` 然后 `node node_modules/next/dist/bin/next start -p 3000`

### DeepSeek 配置（可选）

在项目根目录 `.env.local` 配置：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

左下角 LLM ENGINE 切到「DeepSeek」即走真实模型；任何失败都会在控制台打印
`[engine] ... 回退演示脚本` 并自动切回剧本，演示永不中断。不配置 Key 时保持「演示脚本」即可。

## 演示动线建议（约 4 分钟）

1. **内网体检**：启动序列后自动播放，拓扑节点逐个点亮 → 报告卡（12 / 2 / 1）→
   高危卡（105 MS17-010、108 SSH 弱口令）。可演示悬停 tooltip、节点点击、
   右键菜单、搜索定位、点连线看证据、消息中 IP 点击定位。
2. **蜜点部署**：自动播放停在 105·SSH 授权卡（HITL 核心亮点），点「批准并执行」看部署清单；
   再发「192.168.1.107 上部署 SQL 蜜点怎么处理端口冲突？」演示**四方案决策卡**；
   对 109 部署演示 BLOCKED 卡；诱饵清单里演示卸载授权；
   切「自动执行」后发「根据体检结果自动部署蜜点」演示 Agent 链式自主决策。
3. **归因分析**：自动播放主告警，杀伤链逐层解锁 → 置信因子 → 87% 研判 → 生成处置工单；
   再演示「分析攻击活动 C-0919」「下一条待研判」「分析关联事件 wangwei」
   与误报样本 0906-001（绿色 25% 良性结论）；右栏告警队列与全局态势实时联动。
4. 每页右上角「↻ 重放」重置本页；「自由操作」模式可自由提问
   （资产问答、攻击来源、高危清单、处置工单、画图复现、问候兜底均有剧本）。

## 关键实现

- `src/lib/mock-engine.ts`：拦截 `/chat/completions` 的确定性脚本引擎（SSE 流式、
  思考停顿、打字机、意图状态机、审批两阶段编排、多告警 / campaign / 实体路由、
  DeepSeek 失败回退）。
- `src/lib/mock-data.ts`：12 资产 / 连线 / 蜜点模板与可行性评估 / 9 告警 /
  多 campaign 动态溯源 / 证据时间线 / MITRE / 置信因子 / 14 天趋势。
- `src/lib/app-store.ts`：客户端全局状态（部署按类型隔离、审批、溯源解锁层数、
  引擎 / 授权模式、自动批准类型）。
- `src/lib/approval-bus.ts`：HITL 审批总线（中栏卡片与右栏远程审批共享状态）。
- `src/app/api/copilotkit/[[...slug]]/route.ts`：CopilotKit Runtime + 自定义 fetch 注入，
  从请求头同步引擎 / 授权模式 / 自动批准类型。
- `src/components/`：`TopologyMap`（雷达拓扑）、`AttackGraph`（杀伤链 + 研判卡）、
  `ApprovalCard`（HITL 授权 / 四方案 / 卸载）、`artifacts`（聊天流卡片）、
  `AlertQueue`（告警队列）、`RightPanel`（三页右栏控制台）、`hud`（HUD 组件库）。
- 辅助路由：`/popup`（浏览器弹窗形态）、`/sidebar`（侧边栏形态）、`/single`、`/mcp-apps`。
- AI 文本被脚本约束为 1–2 句短结论，明细一律由 Artifact 卡片与右栏承载，三处信息不重复。
