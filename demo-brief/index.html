演示脚本（给老板，照着走）

Demo Script
00:00 · 开场

展示产品形态

打开 http://localhost:3001，展示三栏界面：左栏 三功能导航（带 kicker 路径）· 中栏 对话会话（顶部 Agent 状态灯 AGENT READY）· 右栏 详情面板。
讲解：这不是传统安全平台，是一个「对话驱动的安全智能体」——像 Codex / Claude Code 一样，以对话为主体完成安全操作。
00:30 · 能力一

内网体检

输入 「对 192.168.1.0/24 做内网体检」 → 状态灯变 AGENT WORKING → 拓扑图节点逐个出现（12/12）→ 高危节点标红 → 右栏进度条 0→100% → 报告卡（12 资产 / 2 高风险）→ AI 生成完整体检报告。
讲解：AI 调用 scanAsset 工具，扫描结果实时渲染成拓扑 Artifact；报告包含攻击链（103→105→108）、弱口令、蜜点部署建议——AI 不只聊天，还能干活。
02:30 · 能力二

蜜点部署

输入 「检测到 105 有 MS17-010，帮我部署 SSH 诱饵；网关有 Web，部署 Web 仿冒」 → 两张部署卡依次出现（SSH 青 / WEB 紫）→ 端口预检通过 → 进度 100% → AI 给出专业建议（补 SMB 诱饵覆盖 445 端口）。
讲解：AI 自主决策部署位置与模板类型，部署过程全可视化；「执行与决策分离」——写操作有预检，AI 只建议不越权。
04:00 · 能力三

归因分析

切到归因页（或直接说 「分析最近一条蜜点告警」）→ 红色告警卡 → 四层溯源图谱逐层展开（事件 → 攻击源 → 跳板 → 失陷账号）→ ATT&CK 链 → 研判结论卡（置信度 87%）。
讲解：从一条蜜点告警回溯完整攻击链——离职账号 wangwei 爆破 105 → MS17-010 横向移动 → 108 触发诱饵；观测证据与行为推断分级标注。
05:30 · 收尾

总结与边界

展示页面稳定状态（状态灯 AGENT READY，可继续对话追问报告细节）。
讲解：当前为 Demo，数据为模拟；三件事已验证 AI 工具调用闭环。真实落地路径：接真实扫描工具（fscan）+ 真实蜜罐（HFish），管理端与内网执行端两级部署——方案已在准备。
演示要点：① 全程强调「对话驱动」——所有操作都是自然语言，不用点按钮；② 等 AI 跑完再讲，不要边跑边讲；③ 若模型偶发卡顿，可刷新页面重新输入（DeepSeek 按量计费，演示成本约几分钱）；④ 准备一句兜底：「数据为模拟，重点看交互范式与 AI 编排能力」。

设计原则

01 执行与决策分离：AI 只能调用白名单工具，写操作走预检；工具返回的真实数据渲染界面，AI 生成的文本永远不算事实。

02 AI 失效可降级：三层防护——服务挂（playbook 直达工具）/ 流中断（结果可重放）/ 幻觉（白名单+确认）。AI 坏不影响核心工具链。

03 两级部署预留：扫描流量贴着资产（内网 agent），跨网络只传小数据（指令+结果）——当前 Demo 单机，架构按两级设计。

应急预案与降级

Resilience

设计即预案：架构本身内置容错

01 AI 只编排不执行：模型失效时工具链照常运行——损失是「没人解说」，不是「系统瘫痪」。

02 工具结果即事实：界面渲染全部来自工具返回数据，AI 文本只是解说，幻觉不污染任何数据。

03 数据先在本地：现场 agent 先落库，通道恢复后补传，断网不丢。

故障场景应对兜底方案
大模型失效
宕机 / 限流 / 超时		 重试 + 演示前预热；AI 只做编排，核心工具链可脱离 AI 独立运行（playbook 直达工具） 本地模型双通道（学校 Ollama 兜底）；按钮直达工具，不依赖对话
大模型幻觉 / 误调用 白名单工具 + 写操作确认流；AI 生成的文本永远不算事实，界面只信工具返回 全程审计日志，误操作可追溯、可回滚
内网禁出站
无法连公网		 agent 走专用 4G/5G 通道回连（与业务网物理隔离）；或 Tailscale 出站（443） 完全隔离场景：全内网部署 + 本地模型，管理端经 VPN 访问
通道中断
链路断开		 agent 本地继续执行 + SQLite 缓存结果，网络恢复后自动补传；心跳检测 + 自动重连 断点续传；管理端任务状态机挂起等待 agent 上线
agent 盒子故障
现场设备损坏		 无状态设计：盒子没有大脑，换一台机器一条命令恢复，重新下发任务即可 多盒冗余（每台数百元，成本极低）
演示现场断网
老板面前掉链子		 前端完全本地运行；模型调用需外网 → 切手机热点应急 预录完整流程视频/截图兜底，断网也能讲完方案

演示现场预案（给老板演示时）

① 演示前 10 分钟完整跑一遍三流程（预热模型 + 确认额度）；② AI 卡住 → 刷新页面重发（会话历史在服务端内存，不丢）；③ 若模型持续异常 → 先讲「三闭环」架构再补演示；④ 万能兜底话术：「数据为模拟，重点看交互范式与 AI 编排能力，真实工具接入是下一步」。
